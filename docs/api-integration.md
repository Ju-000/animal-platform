# 공공데이터 API 연동 메모

## 연동 원칙

- 외부 공공데이터는 유기동물 조회의 기준 데이터로 사용
- 서비스에서 발생하는 관심 등록, 입양 신청, 후원 데이터는 내부 DB에만 저장
- 외부 API 원본 상태값은 그대로 보관하고, 화면 노출용 상태는 내부 상태값으로 별도 관리

## 추천 수집 방식

### 1. 배치 수집

- 하루 여러 번 스케줄러 실행
- 공고 시작일 또는 수정일 기준 증분 수집
- 기존 `desertionNo` 또는 공공 고유값 기준 upsert

### 2. 정규화

- 공공 API 응답에서 날짜, 성별, 중성화 여부, 품종 문자열 정리
- 보호소 코드를 내부 `shelters.external_shelter_code`에 매핑

### 3. 예외 처리

- 이미지 누락 시 기본 이미지 처리
- 보호소 미매핑 시 임시 보호소 또는 미분류 상태 저장
- API 장애 시 마지막 성공 수집 시점 유지

## 내부 상태값 예시

- `PROTECTED`
- `ADOPTION_IN_PROGRESS`
- `ADOPTED`
- `ENDED`
- `URGENT_SUPPORT`

## 관리자 운영 포인트

- 최근 수집 성공 시각 표시
- 수집 실패 로그 확인
- 미매핑 보호소 확인
- 중복 데이터 검수
