# 화면 IA / 와이어 구조 초안

## 1. 전체 사이트맵

### 공통

- `/` 메인
- `/animals` 유기동물 목록
- `/animals/{id}` 유기동물 상세
- `/shelters` 보호소 목록
- `/shelters/{id}` 보호소 상세
- `/donations` 후원 안내
- `/stats` 통계 대시보드
- `/notices` 공지사항
- `/login` 로그인
- `/signup` 회원가입

### 회원

- `/me` 마이페이지 홈
- `/me/favorites` 관심 동물
- `/me/adoptions` 입양 신청 내역
- `/me/donations` 후원 내역
- `/me/profile` 내 정보 관리

### 보호소

- `/shelter-admin` 보호소 대시보드
- `/shelter-admin/animals` 보호 동물 관리
- `/shelter-admin/adoptions` 입양 신청 관리
- `/shelter-admin/donations` 후원 관리
- `/shelter-admin/usages` 후원금 사용 내역
- `/shelter-admin/profile` 보호소 정보 관리

### 관리자

- `/admin` 관리자 대시보드
- `/admin/users` 회원 관리
- `/admin/shelters` 보호소 승인/관리
- `/admin/animals` 유기동물 데이터 관리
- `/admin/donations` 후원 흐름 관리
- `/admin/stats` 운영 통계
- `/admin/notices` 공지 관리

## 2. 주요 사용자 흐름

## 2.1 일반 회원 흐름

1. 메인에서 유기동물 검색
2. 목록에서 필터 적용
3. 상세 페이지 진입
4. 관심 등록 또는 입양 신청 또는 후원
5. 마이페이지에서 진행 상태 확인

## 2.2 보호소 흐름

1. 보호소 계정 로그인
2. 보호소 대시보드 진입
3. 보호 동물 상태 확인
4. 입양 신청 검토
5. 후원 내역 및 사용 내역 관리

## 2.3 관리자 흐름

1. 관리자 로그인
2. 전체 운영 지표 확인
3. 보호소 승인 및 계정 관리
4. 공공데이터 수집 상태 점검
5. 후원/입양 예외 케이스 확인

## 3. 화면별 구성

## 3.1 메인 `/`

- 상단 히어로 영역
  - 지역별 검색
  - 품종/축종 검색
  - 긴급 보호 동물 바로가기
- 섹션 1: 오늘 주목할 보호 동물
- 섹션 2: 긴급 후원이 필요한 동물
- 섹션 3: 가까운 보호소 찾기
- 섹션 4: 최근 입양 성공 사례
- 섹션 5: 운영 통계 요약 카드

## 3.2 유기동물 목록 `/animals`

- 좌측 또는 상단 필터
  - 지역
  - 보호소
  - 축종
  - 품종
  - 성별
  - 중성화 여부
  - 공고 상태
- 검색 결과 카드
  - 이미지
  - 품종
  - 보호소
  - 구조일
  - 상태 배지
  - 관심 등록 버튼
  - 후원 버튼
  - 상세 보기 버튼

## 3.3 유기동물 상세 `/animals/{id}`

- 상단
  - 대표 이미지
  - 상태 배지
  - 기본 정보
- 본문
  - 구조 위치
  - 특징
  - 건강/상태 메모
  - 공고 정보
  - 보호소 카드
- 우측 액션 박스
  - 관심 등록
  - 입양 신청
  - 후원하기

## 3.4 보호소 목록 `/shelters`

- 지도 또는 리스트 전환
- 지역별 필터
- 보호소 카드
  - 이름
  - 주소
  - 연락처
  - 현재 보호 수
  - 누적 후원액

## 3.5 보호소 상세 `/shelters/{id}`

- 보호소 소개
- 연락처/운영시간
- 위치
- 현재 보호 동물 목록
- 최근 입양 처리 현황
- 후원 현황
- 후원하기 버튼

## 3.6 후원 페이지 `/donations`

- 후원 대상 선택
  - 특정 동물
  - 보호소
- 후원 금액 선택
- 결제 수단 선택
- 후원 완료 화면
- 후원 내역 확인 연결

## 3.7 통계 페이지 `/stats`

- 기간 필터
- 지역 필터
- 카드 지표
  - 총 보호 동물 수
  - 입양 완료 수
  - 관심 등록 수
  - 후원 총액
- 차트
  - 지역별 보호 동물 수
  - 월별 입양 신청 수
  - 월별 후원액
  - 보호소별 입양 성공률

## 4. 역할별 대시보드 차이

## 회원 마이페이지

- 최근 관심 동물
- 최근 입양 신청 상태
- 최근 후원 내역
- 추천 보호 동물

## 보호소 대시보드

- 현재 보호 동물 수
- 입양 신청 대기 건수
- 이번 달 후원액
- 최근 문의/신청 목록

## 관리자 대시보드

- 오늘 API 수집 상태
- 미승인 보호소 수
- 후원 실패 건수
- 입양 처리 지연 건수
- 전체 누적 통계

## 5. UI 설계 원칙

- 게시판처럼 글 제목 나열 중심으로 가지 않음
- 목록은 카드형 + 상태 배지 중심
- 액션 버튼은 상세 페이지에서 명확하게 제공
- 관리자/보호소 화면은 표 + 카드 + 차트 혼합
- 통계 화면은 숫자 카드와 차트 중심
